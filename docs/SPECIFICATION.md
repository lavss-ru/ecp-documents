# ECP Documents

> Плагин WordPress для публикации документов, подписанных электронной подписью (PDF + SIG).

**Статус:** Draft
**Версия документа:** 1.0
**Дата:** 2026-07-28

---

## 1. Назначение проекта

**ECP Documents** — это плагин для WordPress, предназначенный для публикации документов, подписанных электронной подписью (PDF + SIG), непосредственно в содержимом страниц и записей.

Плагин не является системой управления документами и не заменяет электронный архив.

Основная задача плагина — предоставить редактору WordPress простой и понятный инструмент для добавления документов с электронной подписью в любом месте страницы без необходимости использовать шорткоды, HTML или специальные знания.

Плагин использует стандартные возможности WordPress, включая медиатеку, и максимально интегрируется в привычный процесс работы редактора.

---

## 2. Цели проекта

При разработке плагина ставятся следующие цели:

- простота использования для редакторов WordPress;
- естественная интеграция в интерфейс WordPress;
- использование стандартных возможностей WordPress;
- отсутствие лишнего функционала;
- возможность размещения нескольких документов на одной странице;
- совместимость с современными версиями WordPress;
- лёгкость сопровождения и дальнейшего развития проекта.

Основной принцип проекта:

> **Один плагин — одна задача.**

---

## 3. Возможности плагина

Плагин предоставляет редактору WordPress следующие возможности:

- добавление документа с электронной подписью в любое место страницы или записи;
- указание названия документа;
- выбор PDF-файла из стандартной медиатеки WordPress;
- выбор файла электронной подписи (SIG) из стандартной медиатеки WordPress;
- размещение нескольких документов на одной странице;
- изменение ранее вставленного документа;
- удаление документа из содержимого страницы без удаления файлов из медиатеки;
- корректное отображение документа на публичной части сайта.

Все действия выполняются непосредственно в редакторе WordPress и не требуют специальных знаний.

---

## 4. Ограничения проекта

Плагин сознательно не предоставляет следующий функционал:

- не является системой электронного документооборота;
- не является архивом документов;
- не ведёт каталог документов;
- не использует категории, теги или папки для документов;
- не содержит отдельной страницы управления документами;
- не изменяет стандартную работу медиатеки WordPress;
- не выполняет криптографическую проверку электронной подписи;
- не хранит документы вне стандартной медиатеки WordPress.

Все перечисленные ограничения являются осознанными архитектурными решениями и направлены на сохранение простоты, понятности и удобства использования плагина.

---

## 5. Требования

Плагин должен соответствовать следующим требованиям:

- работать на поддерживаемых версиях WordPress;
- использовать стандартный API WordPress;
- соблюдать стандарты разработки WordPress;
- быть совместимым с Classic Editor;
- не нарушать работу других плагинов;
- использовать медиатеку WordPress для хранения файлов;
- иметь простой и минималистичный пользовательский интерфейс;
- не требовать дополнительных зависимостей или внешних сервисов для основной работы.

---

## 6. Совместимость

Первая стабильная версия плагина должна поддерживать:

- WordPress 7.x и выше;
- PHP 8.2 и выше;
- Classic Editor.

Поддержка редактора Gutenberg рассматривается как отдельный этап развития проекта и не должна изменять общую модель работы плагина.

---

## 7. Термины

В рамках проекта используются следующие термины:

- **Документ** — PDF-файл, публикуемый на странице или записи.
- **Файл подписи** — файл с расширением `.sig`, относящийся к соответствующему PDF-документу.
- **Документ с ЭП** — пара файлов (PDF + SIG), отображаемая пользователю как единый объект.
- **Медиатека** — стандартная библиотека файлов WordPress, используемая для хранения PDF- и SIG-файлов.
- **Редактор** — пользователь WordPress, имеющий право редактировать содержимое страниц и записей.

---

## 8. Пользовательский интерфейс

Плагин интегрируется непосредственно в редактор WordPress.

Редактор может добавить документ с электронной подписью с помощью команды **«Документ с ЭП»**.

При выборе команды открывается диалоговое окно, позволяющее:

- указать название документа;
- выбрать PDF-файл из медиатеки WordPress;
- выбрать соответствующий файл подписи (SIG);
- подтвердить вставку документа.

После подтверждения документ вставляется в текущее положение курсора как единый элемент содержимого страницы.

Интерфейс плагина должен быть простым, понятным и соответствовать общему стилю WordPress.
