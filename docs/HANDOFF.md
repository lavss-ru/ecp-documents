# О проекте

**ECP Documents** — плагин WordPress для публикации документов, подписанных электронной подписью (ЭЦП).

Основная задача плагина — предоставить простой и понятный способ публикации PDF-документов вместе с файлом электронной подписи (`.sig`), используя стандартные возможности WordPress.

Проект создаётся прежде всего для:

- государственных учреждений;
- образовательных организаций;
- муниципальных сайтов;
- организаций, публикующих официальные документы.

---

# Главные цели проекта

Версия **1.0** должна позволять пользователю:

- выбрать PDF из Media Library;
- выбрать файл SIG;
- автоматически сформировать shortcode;
- вставить shortcode в Classic Editor;
- вывести документ на сайте;
- предоставить ссылки для скачивания PDF и SIG;
- показать посетителю, что документ подписан электронной подписью.

Главная цель проекта — простота, стабильность и долговременная поддерживаемость.

# Следующая задача

Следующий логически завершённый этап разработки:

**Автоматическая вставка shortcode в Classic Editor.**

Необходимо реализовать:

- validate();
- buildShortcode();
- insertDocument();

После выбора PDF и SIG пользователь должен получить автоматически сформированный shortcode, который вставляется в текущую позицию курсора редактора.

# Архитектурные принципы

При разработке необходимо соблюдать следующие принципы.

## Использовать стандартный WordPress API

Не изобретать собственные механизмы там, где WordPress уже предоставляет готовое решение.

---

## Использовать Media Library

Все PDF и SIG должны храниться исключительно в Media Library.

Собственное файловое хранилище не используется.

---

## Использовать attachment_id

Во внутренних структурах проекта сохраняются только attachment_id.

Причины:

- переносимость;
- совместимость;
- отсутствие проблем при переносе сайта;
- использование стандартного API WordPress.

---

## Поддерживать Classic Editor

Основной редактор проекта — Classic Editor.

Поддержка Gutenberg может появиться позднее, но не должна усложнять архитектуру первой версии.

---

## Shortcode является публичным API

Основной способ публикации документов:

```
[ecp_document title="Приказ №1" pdf_id="123" sig_id="456"]
```

Изменение структуры shortcode допускается только при наличии веских причин.
