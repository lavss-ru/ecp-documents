# Назначение документа

Этот документ описывает план развития проекта **ECP Documents**.

Roadmap определяет направления развития, приоритеты и основные этапы разработки.

Документ не является техническим заданием. Подробные требования описаны в `SPECIFICATION.md`.

---

# Текущее состояние

На текущий момент реализована базовая архитектура проекта.

Подготовлены:

- структура проекта;
- Composer и PSR-4;
- административная часть;
- интеграция с WordPress Media Library;
- выбор PDF;
- выбор SIG;
- автоматическое определение названия документа;
- комплект проектной документации.

---

# Основные принципы

При развитии проекта необходимо соблюдать следующие правила:

- не усложнять архитектуру без необходимости;
- сохранять совместимость с предыдущими версиями;
- использовать стандартный WordPress API;
- избегать лишних зависимостей;
- каждая новая возможность должна решать реальную задачу пользователя.

# Идеи на будущее

Следующие возможности могут быть рассмотрены, но не входят в текущий план разработки:

- статистика скачиваний;
- REST API;
- импорт и экспорт данных;
- поддержка нескольких файлов подписи;
- пакетная публикация документов;
- интеграция с внешними сервисами проверки ЭЦП.

Эти функции будут реализовываться только при наличии практической необходимости.

---

# Что не планируется

На текущий момент проект **не ставит целью** стать универсальной системой электронного документооборота.

Также не планируется:

- собственое файловое хранилище;
- замена стандартной Media Library;
- сложная система управления документами;
- избыточные административные настройки.

Проект должен оставаться небольшим, понятным и простым в сопровождении.
